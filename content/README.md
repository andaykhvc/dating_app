# content/

The source of truth for every lesson. The database is built from these files:

```bash
npm run content:validate   # check
npm run content:build      # → supabase/seed/0010–0014_learn_*.sql
```

Architecture, rules and how-tos: [`docs/content-system.md`](../docs/content-system.md).

## Files

| Path | What |
| --- | --- |
| `languages.json` | Languages with content: name, flag, speech locale, noun articles (for gender and article-less answers), `core` (must be complete). |
| `sources.json` | Provenance registry. Every row of content names one of these. |
| `curriculum.json` | Courses, then units (ordered) with their skills. |
| `blocklist.json` | Whole words that must never appear. A tripwire for imports. |
| `concepts/*.tsv` | Concepts. Editorial files also carry one column per language. |
| `concepts/cldr.tsv` | Generated by `npm run content:import:cldr`. Do not edit. |
| `<lang>/*.tsv` | Per-language rows (`key`, `text`, optional `note`, `ext_id`, `author`, `license`, `status`). Used by imports and for adding a language without touching the concept files. |
| `imported/` | Review reports (e.g. Wikidata). Never loaded by the build. |

A `#source: <id>` line in a file sets the source for every row in it (default
`lingua-match-editorial`). Lines starting with `#` are comments.

## Concept columns

`key` · `kind` · `pos` · `cefr` · `skill` · `topic` · one column per language ·
`situation` · `flags`

- **key** — stable, lower-case, never renamed (progress hangs off it). Sentences
  use an `s.` prefix by convention.
- **kind** — `w` word, `p` phrase (fixed expression, e.g. "see you later"),
  `s` sentence.
- **pos** — for words: `noun`, `verb`, `adjective`, `adverb`, `pronoun`,
  `preposition`, `conjunction`, `determiner`, `numeral`, `interjection`.
  Distractors are chosen by it.
- **cefr** — blank = the unit's level.
- **topic** — semantic field for distractors (`drinks`, `weekdays`…); blank =
  the skill key.
- **situation** — English, for "What would you say?" exercises.
- **flags** — `;`-separated: `social` (offered as "use it with a match"),
  `proper` (proper noun, no article expected), `group=<name>` (never distract
  each other), `gloss=<text>` (editor description when the English cell is
  ambiguous), `status=needs_review|disabled`, `cefr=A2`.

## Cell syntax (language columns)

| Syntax | Meaning | Example |
| --- | --- | --- |
| `text` | The text learners see | `der Kaffee` |
| ` \| ` | Further accepted answers when typing | `Wie geht's? \| Wie geht es dir?` |
| `[word]` | The gap in fill-the-gap exercises | `Ich [trinke] jeden Morgen Kaffee.` |
| `[word:pos]` | Gap with its part of speech (so wrong options match) | `Ich [trinke:verb] jeden Morgen Kaffee.` |
| `{m}` `{f}` `{n}` `{c}` `{pl}` | Grammatical gender when the article does not show it | `el agua {f}` |

Nouns take their article in de/es/nl (`der Kaffee`, `el café`, `de koffie`);
the article-less form is accepted automatically. English verbs are written
`to eat`; `eat` is accepted automatically.

Keep sentences short and natural: A1 ≤ 9 words, A2 ≤ 12 words, one sentence,
final `. ! ?`, Spanish questions with `¿`.
